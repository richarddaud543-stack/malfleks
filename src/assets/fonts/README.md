# Fonts for generated images

Two faces the site already uses on its pages (loaded there through
`next/font/google`), kept here as files because the image generator behind
`src/app/opengraph-image.tsx` and the icon routes cannot read `next/font` and
does not understand `.woff2`.

- `bricolage-grotesque-latin-600-normal.woff` — Bricolage Grotesque, SemiBold.
  Copyright 2022 The Bricolage Grotesque Project Authors.
- `instrument-serif-latin-400-italic.woff` — Instrument Serif, Italic.
  Copyright 2022 The Instrument Serif Project Authors.

Both are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), taken unmodified from the `@fontsource`
packages of the same names.
